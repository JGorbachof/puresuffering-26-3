# Release verification
PSQC.java is the private standalone GameTest fixture used against the exact packaged JAR. It requires a separate NeoForge ModDevGradle 2.0.148 Java 25 GameTestServer harness, with mod ID psqc and a minecraft:function test instance bound to psqc:invasions. The harness uses an embedded survival player, production invasion manager, event handlers, native storage, packet codecs and actual server ticks. It does not simulate a real remote client or a full multi-day survival game. release-audit.json records source target and asset-history checks. This fixture is provided for transparency; it is not compiled by the mod build.
